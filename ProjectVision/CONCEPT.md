# AgentRouter — 核心概念

> **多开源 CLI 编程助手调度器**

---

## 一句话定义

一个桌面平台，**不写代码，只调度**——把多个开源 CLI 编程助手整合到一起，像管一个团队一样管它们。

---

## 核心定位

```
╔══════════════════════════════════════╗
║          AgentRouter                 ║
║       「多 CLI 编程助手调度器」        ║
╠══════════════════════════════════════╣
║                                      ║
║    ❌ 不做 IDE                       ║
║    ❌ 不做新 CLI                     ║
║    ❌ 不做能力增强                   ║
║                                      ║
║    ✅ 只做一件事：调度               ║
║       · 调用（Call）— spawn CLI     ║
║       · 维护（Maintain）— 记上下文   ║
║                                      ║
╚══════════════════════════════════════╝
```

---

## 概念模型

| 概念 | 职责 |
|---|---|
| **调度器（Scheduler）** | 谁来做、什么时候做、怎么做 |
| **Agent 适配器（Adapter）** | 翻译平台指令↔CLI 参数 |
| **任务（Task）** | 最小工作单元，有 assignee 和依赖 |
| **会话（Session）** | 一次需求的完整生命周期 |
| **项目（Project）** | 一个本地代码仓库 = 一个项目 |

---

## 价值主张

> **「不绑架，不纠结」**

| | Cursor / Windsurf | AgentRouter |
|---|---|---|
| **生态** | 封闭 | **开放** — 爱用什么开源 CLI 用什么 |
| **定位** | 全家桶 IDE | **调度中心** |
| **哲学** | 我们的厨子最好 | 你带厨子，我搭厨房 |

## 性价比优势

> **把对的开源 CLI 放在对的位置上，让每个工具做自己最擅长的事。**

```
Reasonix 🧠 — 建筑师：画图纸、拆任务、审质量
CodeWhale 💻 — 施工队：按图纸干活、实现代码

1+1 > 2，全是开源的，全是低成本的。
```
