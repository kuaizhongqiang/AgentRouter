# AgentRouter — 用户画像

---

## 核心用户：独立开发者

### 类型 B：深度用户 🧠

| 维度 | 描述 |
|---|---|
| **背景** | 使用 AI coding 工具半年以上，试过 3+ 款 |
| **现状** | 知道各 CLI 优劣势，但手动切换太烦 |
| **痛点** | 没有一个统一平台管理自己心仪的工具 |
| **诉求** | 我要的是"指挥中心"，不是"又一个新工具" |

### 类型 C：初学者 🐣

| 维度 | 描述 |
|---|---|
| **背景** | AI coding 刚入门，被开源产品看花眼 |
| **现状** | 不知道选 Reasonix 还是 CodeWhale |
| **痛点** | 选错工具成本太高，不敢轻易下注 |
| **诉求** | 先让我都用用，爱用什么用什么 |

---

## 未来用户：小团队

| 维度 | 描述 |
|---|---|
| **背景** | 3-10 人技术团队 |
| **现状** | 各用各的 AI 工具，缺乏统一标准 |
| **痛点** | 代码风格不一致、上下文不共享 |
| **诉求** | 团队级别的调度、权限、审计 |

---

## 用户故事

> _作为一个独立开发者，我希望用一个平台调度多个开源 CLI 编程助手，让它们各司其职、协同工作，而不是在终端窗口之间手动搬砖。_
