# AgentRouter — 用户画像

---

## 核心用户：独立开发者

### 类型 B：深度用户 🧠

| 维度 | 描述 |
|---|---|
| **背景** | 使用 AI coding 工具半年以上，试过 3+ 款产品 |
| **现状** | 知道各 CLI 的优劣势，但来回切换、搬运上下文很烦 |
| **痛点** | 没有一个统一平台来管理自己心仪的工具 |
| **诉求** | 我要的是"指挥中心"，不是"又一个新工具" |

### 类型 C：初学者 🐣

| 维度 | 描述 |
|---|---|
| **背景** | AI coding 刚入门，被开源产品眼花缭乱劝退 |
| **现状** | 不知道选 Reasonix、CodeWhale 还是 Continue.dev |
| **痛点** | 选错工具的成本太高，不敢轻易下注 |
| **诉求** | 先让我都用用，爱用什么用什么 |

---

## 未来用户：小团队

| 维度 | 描述 |
|---|---|
| **背景** | 3-10 人技术团队，有 Tech Lead |
| **现状** | 团队各用各的 AI 工具，缺乏统一标准 |
| **痛点** | 代码风格不一致、上下文不共享、项目管理混乱 |
| **诉求** | 团队级别的调度、权限、审计 |

---

## 核心价值主张

> **「不绑架，不纠结」**

| | Cursor / Windsurf | AgentRouter |
|---|---|---|
| **生态** | 封闭——只能用自家模型 | **开放**——爱用什么开源 CLI 用什么 |
| **定位** | 全家桶 IDE | **调度中心** |
| **用户** | 不想折腾的人 | 想自己掌控的人 |
| **哲学** | 我们的厨子最好 | 你带厨子，我搭厨房 |

---

## 一句话用户故事

> _作为一个独立开发者，我希望用一个平台调度多个开源 CLI 编程助手，让它们各司其职、协同工作，而不是在终端窗口之间手动搬砖。_
